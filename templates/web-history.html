History of the Web

The World Wide Web (WWW) is a system of websites and web pages that are accessed through the Internet using web browsers. Created by Tim Berners-Lee around 1990, the Web made it much easier for people to access, connect, and share information online.

Internet History

Web Timeline

1989 - The Web is proposed:

Tim Berners-Lee, working at CERN, proposed a system for sharing and connecting information between computers using hypertext.

https://home.cern/world-wide-web-35/

1990 - Core Web technologies created:

Berners-Lee developed the main technologies behind the Web: HTML for creating pages, HTTP for transferring them, and URLs for identifying their locations. He also created the first web browser and web server.

https://home.cern/science/computing/the-birth-of-the-web/

1973-1974 - TCP/IP:

Vint Cerf and Bob Kahn developed the foundations of TCP/IP, the communication protocols that allow different computer networks to communicate.

https://www.computerhistory.org/internethistory/1970s/

1983 - Birth of the modern Internet:

ARPANET officially switched to TCP/IP on January 1, 1983. This is often considered a major starting point of the modern Internet.

https://www.darpa.mil/news/features/arpanet

1991 - First website goes public:

The world's first website became publicly accessible. It explained what the World Wide Web was and how people could use it.

https://home.cern/cern-celebrates-web-anniversary/

1993 - The Web becomes freely available:

CERN made the Web's technology available without royalties, helping it spread worldwide. The Mosaic browser also appeared, making websites much easier and more visual to use.

https://home.cern/web30-30-year-anniversary-invention-changed-world/
 https://www.ncsa.illinois.edu/about/history/

1994 - Web standards:

Berners-Lee founded the World Wide Web Consortium (W3C) to develop common standards so that websites and browsers could work together.

https://www.w3.org/about/history/

Mid-to-late 1990s - Rapid growth:

Websites became common for businesses, news, communication, and entertainment. Technologies such as JavaScript and CSS made websites more interactive and visually advanced.

https://www.computerhistory.org/timeline/1995/
 https://www.w3.org/press-releases/1996/css1-rec/

2014 - HTML5:

Technologies such as HTML5 allowed browsers to support video, audio, graphics, and increasingly powerful web applications.

https://www.w3.org/press-releases/2014/html5-rec/
